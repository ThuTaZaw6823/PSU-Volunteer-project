# English Fun Camp — PSU student volunteer project

A responsive static project showcase for Phuket Sunshine Village Foundation.

## Content

The text comes from the supplied English Fun Camp presentation and Volunteer Poster. The presentation reports 50 children, 11 volunteers, four activity stations, target ages 7–12, and average scores of 4.32/5 before and 4.50/5 after the camp. The page does not infer an event date or a test sample size. Telephone Game is also called Spell in the teaching plan. The supplied location is 7.8827438, 98.4245272.

Seven unique project photos are included; the identical duplicate was omitted. Images are resized and stripped of camera metadata for web delivery. The project mark is an original decorative book-and-sun icon, not a university crest.

The university identity strip uses the three supplied logo files: the PSU emblem, PSU Phuket Campus wordmark, and College of Computing logo. These assets are copied unchanged and displayed at their original aspect ratios on a white background.

## Editing

Edit page text in `index.html`, styling in `styles.css`, and photo captions/categories in `app.js`. Add images to `assets` and register them in the `photos` array. The page does not collect visitor data or provide an upload service.

The QR SVG and PNG encode the expected canonical site origin. If the site URL changes, regenerate both and update the canonical sharing metadata, `projectUrl`, and `qr.html`. Sharing restrictions are controlled by Sites, separately from QR encoding.

## Preview

Serve `dist` using a local static HTTP server, for example `python3 -m http.server 4173`.
